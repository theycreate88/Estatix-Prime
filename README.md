# Estatix Prime

A modern real estate platform crafted with clarity, performance, and a seamless property-browsing experience in mind.

Estatix Prime reflects the effort poured into every detail — from the layout structure and responsive behavior to typography, spacing, visual hierarchy, and smooth user interactions. Every component has been intentionally shaped to feel clean, premium, and intuitive.

Example:


## Overview

Estatix Prime is a modern real estate platform built with **Next.js, React, and Tailwind CSS**. It provides a polished and responsive interface for browsing real estate projects and exploring company information.

The project focuses on delivering a premium user experience through carefully structured layouts, reusable components, responsive design, smooth interactions, and multiple homepage styles.

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm

Check your installed versions:

```bash
node -v
npm -v
```

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project:

```bash
cd Estatix-Prime
```

Install the dependencies:

```bash
npm install
```

### Run the Development Server

Start the development server:

```bash
npm run dev
```

Open the application in your browser:

```text
http://localhost:3000
```

## Production Build

Create an optimized production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
